## Карточка текущей задачи
ID: E01
Цель: сделать среду пользователя наблюдаемой и воспроизводимой, не менять методологию.
Входы: README.md, requirements.txt, pyproject.toml, фактические версии инструментов.
Разрешённые изменения: только явно согласованная настройка окружения и документация.
Не входит: новые модели, тюнинг, изменения данных, полный расчёт, публикация GitHub.
Результат: сведения об окружении и текст вывода команд.

## Правило принятия результата
Сначала проверяются корректность и сопоставимость; только затем улучшение метрик.
Не менять правила теста ради выигрыша. Неудачные эксперименты сохранять.
По окончании задачи обновлять статус и указывать реальный путь к подтверждающему результату.
