## Время и оригинальные версии

`published_at`, `event_date`, `updated_at`, `available_at` и `retrieved_at` — разные поля. Дата события не задаёт доступность. Неподтверждённый современный текст доступен только при загрузке. Если известна только календарная дата публикации, применяется консервативный конец дня в Europe/Moscow; совершенно неизвестная дата исключается из корпуса периода. Точность публикации и обновления хранятся отдельно; точный будущий update не принимается. Origin E01 остаётся последним календарным днём месяца **в 00:00 Europe/Moscow**; дата не расширяется до конца суток.

Для четырёх PDF повторно проверены SHA самого PDF, текста и официального архивного указателя, заголовок, датированная ссылка и совпадение дат создания/изменения PDF с выпуском. Метаданные PDF сами по себе доказательством не являются. Принято прежнее явно названное допущение E05a: доверие датированному оригинальному официальному архиву. Независимых SHA-снимков 2023–2024 нет. Используется только оригинальный заголовок и его строки; HTML-пресс-релизы этим допущением автоматически не подтверждаются.

Оригинальные версии: [16.02.2024](https://cbr.ru/Collection/Collection/File/48891/forecast_240216.pdf), [26.04.2024](https://www.cbr.ru/Content/Document/File/160781/forecast_240426.pdf), [26.07.2024](https://cbr.ru/Content/Document/File/162284/forecast_240726.pdf), [25.10.2024](https://cbr.ru/Content/Document/File/166586/forecast_241025.pdf). Старые файлы читаются; pdftotext повторно не вызывается. Его прежний ненулевой return code и факт отдельной проверки извлечённого текста сохраняются в provenance.

Общий флаг исторических свидетельств рассчитывается отдельно к каждой O. Только документы с `published_at <= available_at <= O` допускаются в признаки. Обновление и будущие дубли не переписывают первый известный снимок. `event_date` без отдельного подтверждения остаётся пустым; дата публикации не копируется в него автоматически.

Сетевой процесс импортировал parser до исправления отдельной precision обновления; его версия зафиксирована SHA run3 в collection_inspection.json. Frozen corpus не переписывался. По сохранённым raw metadata проверено: все имеющиеся 71 updates Lenta содержат точное время, updates после retrieval: 0; CBR updated_at не содержит. Поэтому исправление не изменяет фактическую доступность этого корпуса. Новые запуски сохраняют updated_date_precision; в исходных старых снимках оно неизвестно. Время PDF 23:59:59 Москвы является консервативным представлением календарной даты, а не измеренным временем публикации. Эти четыре события — macro_policy/announcement/unknown, а не автоматически извлечённые решения о ставке.

## Готовность к E07

**E06b выполнен как воспроизводимый pipeline и ограниченный реальный корпус:** event table и feature table действительно построены. **Полноценный исторический news-based E07 пока не готов:** Lenta и HTML-релизы не имеют подтверждённого исторического текста, региональных/муниципальных исторически допущенных событий нет, sample архива неполон. Четыре PDF дают редкие общие national-сигналы и не заменяют региональные новости.

Следующий конкретный шаг — отдельный протокол E07: независимая разметка будущего события и решение о достаточности исторических источников. Для проверки вклада новостей сначала нужны подтверждённые исторические версии или явно согласованный отдельный сценарий неподтверждённых версий. Сам classifier здесь не запускается.
